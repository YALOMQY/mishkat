# مشكاة — تطبيق إسلامي متكامل

تطبيق ويب تقدّمي (PWA) مع غلاف iOS أصلي. في تطبيق iPhone، صفحات المصحف والأذكار مرفقة. في الويب، اختر «تجهيز» وانتظر اكتمال حفظ الصفحات الـ604 قبل الاعتماد على القراءة دون إنترنت. التلاوات والمراجع والكتب غير المحفوظة تحتاج اتصالًا.

## المميزات

| القسم | التفاصيل |
|---|---|
| **مواقيت الصلاة** | حساب فلكي على الجهاز نفسه (بدون إنترنت)، ١٥ طريقة حساب معتمدة (أم القرى، رابطة العالم الإسلامي، المصرية، كراتشي، ISNA…)، مذهب العصر (الجمهور/الحنفي)، تعديل يدوي بالدقائق لكل صلاة، منتصف الليل والثلث الأخير والإمساك، ومعالجة خطوط العرض العالية والمناطق القطبية. |
| **التنبيهات** | تنبيه لكل صلاة (يُفعّل/يُوقف منفرداً)، تذكير قبل الأذان بمدة تختارها، أذان صوتي (٦ أصوات + نغمة تعمل بدون إنترنت)، وتذكير أذكار الصباح والمساء. |
| **القرآن الكريم** | المصحف كاملاً بالرسم العثماني (١١٤ سورة، ٦٢٣٦ آية) مخزّن داخل التطبيق، عرض مصحفي أو آية بآية، بحث في النصّ بدون تشكيل، فهرس السور والأجزاء، علامات محفوظة، متابعة آخر قراءة، تكبير الخط، وتلاوة صوتية لـ ١٢ قارئاً مع تتبّع الآية وتكرارها. |
| **الأذكار** | حصن المسلم كاملاً: ١٣٢ باباً و٢٦٧ ذكراً، عدّاد لكل ذكر يحفظ تقدّمك، بحث، ونسخ. |
| **القبلة** | بوصلة موجِّهة تقول لك «استدر يميناً ٤٥ درجة» حتى تنطبق، مع قطاع سماح ±٥° وتوهّج واهتزاز عند المطابقة، ومؤشّر دقّة المستشعر. وعلى الأجهزة بلا بوصلة تتحوّل تلقائياً لوضع الزاوية الثابتة من الشمال الحقيقي. |
| **السبحة** | عدّاد إلكتروني بأهداف (٣٣ / ١٠٠ / ١٠٠٠) واهتزاز ومجموع تراكمي. |

## التشغيل

```bash
cd "/Users/younisalomqy/تطبيق اسلامي" && python3 -m http.server 8777
```

ثم افتح `http://localhost:8777` — لا يعمل بفتح `index.html` مباشرة (لأن المتصفح يمنع `fetch` من `file://`).

## التثبيت على الجوال

1. ارفع المجلد على أي استضافة تدعم **HTTPS** (Netlify / Cloudflare Pages / GitHub Pages — كلها مجانية وتقبل سحب المجلد وإفلاته).
2. **آيفون:** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
3. **أندرويد:** افتح الرابط في Chrome ← القائمة ← «تثبيت التطبيق».

> HTTPS ضروري: البوصلة والموقع والتنبيهات والعمل أوفلاين لا تعمل بدونه (عدا `localhost`).

## ملاحظات مهمة

- **التنبيهات في الخلفية:** على أندرويد تعمل بشكل جيد بعد التثبيت. على آيفون تتطلب iOS 16.4+ والتثبيت على الشاشة الرئيسية، وتبقى أقل موثوقية من تطبيق أصلي — التنبيه مضمون ما دام التطبيق مفتوحاً.
- **دقة المواقيت:** الحساب مطابق للمراجع المعتمدة ضمن ±دقيقة واحدة (تمّت مقارنته بمكة والرياض والقاهرة ولندن). عند اختلافه مع تقويم مسجدك استخدم «تعديل يدوي للمواقيت» في الإعدادات.
- **التلاوة الصوتية والأذان** تحتاج إنترنت أول مرة ثم تُحفظ تلقائياً. زر «حفظ الأذان للاستخدام أوفلاين» في الإعدادات يحفظه مسبقاً.

## تطبيق iOS الأصلي (جاهز ويعمل)

مشروع Xcode كامل في `ios/` يغلّف تطبيق الويب داخل `WKWebView` ويضيف خدمات النظام:

```bash
open "ios/Mishkat.xcodeproj"     # ثم اختر سمليتر واضغط ⌘R
```

أو من الطرفية:

```bash
cd ios && xcodebuild -project Mishkat.xcodeproj -scheme Mishkat -configuration Debug -destination 'platform=iOS Simulator,name=iPhone 17 Pro' -derivedDataPath build build && xcrun simctl install booted build/Build/Products/Debug-iphonesimulator/Mishkat.app && xcrun simctl launch booted com.dakomn.mishkatapp
```

### ما الذي يضيفه الغلاف الأصلي

| الخدمة | التفاصيل |
|---|---|
| **تنبيهات النظام** | `UNUserNotificationCenter` يجدول حتى ٦٠ تنبيهاً لأسبوع كامل، **تعمل والتطبيق مغلق تماماً**، بمستوى `timeSensitive` للأذان. هذا الفرق الأساسي عن نسخة الويب. |
| **صوت الأذان** | ٦ أذانات مضمّنة بصيغة `CAF/IMA4` (٢٩ ثانية — سقف iOS ٣٠) **مرفقة بالإشعار نفسه** لا كمقطع صوتي، فيتحكّم بها النظام: تظهر مع البانر، وتُسكت بزر خفض الصوت أو بمفتاح الصامت. تعمل بدون إنترنت. |
| **الموقع** | `CoreLocation` مباشرةً — يُحدَّد تلقائياً عند أول تشغيل بعد منح الإذن. |
| **البوصلة** | `trueHeading` من مستشعر النظام (الشمال الحقيقي، أدقّ من بوصلة الويب). |
| **الملفات** | `WKURLSchemeHandler` على مخطّط `mishkat://` — ضروري لأن `WKWebView` يمنع `fetch()` من `file://`. |

مصدر واحد للحقيقة: مرحلة بناء `Embed web app` تنسخ ملفات الويب من جذر المشروع إلى الحزمة في كل بناء — عدّل ملفات الويب فقط، ولا تكرّرها داخل `ios/`.

### الرفع إلى TestFlight

**يتطلّب عضوية Apple Developer Program المدفوعة (٩٩$ سنوياً).** الحساب المجاني لا يملك وصولاً إلى App Store Connect إطلاقاً، ويفشل بالخطأ `No Accounts with App Store Connect Access`.

بعد الاشتراك من [developer.apple.com/programs](https://developer.apple.com/programs):

1. استخدم سجلّ التطبيق المنشور في [App Store Connect](https://appstoreconnect.apple.com) بمعرّف الحزمة `com.dakomn.mishkatapp` والاسم «مشكاة».
2. شغّل:

```bash
cd "/Users/younisalomqy/تطبيق اسلامي/ios" && ./release.sh
```

3. في App Store Connect ← **TestFlight**: أجب على سؤال تصدير التشفير (لا)، وأضف المختبرين.

الاختبار الداخلي (حتى ١٠٠ شخص من فريقك) يبدأ فوراً. الاختبار الخارجي (حتى ١٠٬٠٠٠) يمرّ بمراجعة Apple — عادةً يوم إلى يومين.

المشروع مجهّز بالكامل لذلك: توقيع تلقائي، `PrivacyInfo.xcprivacy`، إقرار عدم استخدام تشفير خاضع للقيود، وأيقونة ١٠٢٤. الأرشفة تنجح فعلياً — الناقص فقط حساب يملك صلاحية الرفع.

### التشغيل على جهازك الحقيقي

الجهاز الحقيقي يرفض أي تطبيق غير موقّع، لذا يلزم مرّة واحدة:

1. **Xcode ← Settings (⌘،) ← Accounts ← +** ← Apple ID ← سجّل الدخول (الحساب المجاني يكفي).
2. اختر هدف **Mishkat** ← تبويب **Signing & Capabilities** ← **Team** ← اختر `(Personal Team)`.
3. اختر جهازك من شريط الأعلى واضغط **⌘R**.
4. أول مرة على الجهاز: **الإعدادات ← عام ← VPN وإدارة الجهاز** ← وثّق حساب المطوّر.

> بالحساب المجاني ينتهي التطبيق بعد ٧ أيام — أعد التشغيل من Xcode لتجديده. حساب المطوّر المدفوع ($99/سنة) يجعله سنة كاملة ويسمح بالنشر على App Store.

إعدادات التوقيع في المشروع تلقائية للتطبيق `com.dakomn.mishkatapp` والودجت `com.dakomn.mishkatapp.MishkatWidget`، ومعطّلة للسمليتر — فيبقى بناء السمليتر يعمل بدون أي حساب.

## Firebase Cloud Messaging

لإعداد إرسال الإشعارات للعملاء عبر Firebase، اتبع [دليل Firebase Cloud Messaging لمشكاة](docs/FIREBASE_PUSH.md). يستخدم الدليل معرّف الحزمة المنشور `com.dakomn.mishkatapp`، ويغطي تسجيل تطبيق iOS، تنزيل `GoogleService-Info.plist` من Firebase، رفع مفتاح APNs، اختبار الرسائل، إطلاق الحملات ومتطلبات الخصوصية.

> لا يُنشأ ملف `GoogleService-Info.plist` يدويًا، ولا تُحفظ مفاتيح APNs أو رموز الأجهزة داخل المستودع.


## تسمية الموقع

عند تحديد الموقع يُعرض اسم مفهوم لا إحداثيات، بثلاث طبقات متتالية:

1. **`CLGeocoder`** في تطبيق iOS — أدقّها، يعطي «الشحر، حضرموت» بالعربية من نظام التشغيل.
2. **أقرب مدينة** خلال ٣٥ كم من جدول المدن المضمّن، لتجنب إظهار مدينة بعيدة.
3. **أقرب محافظة/منطقة** خلال ٤٥٠ كم من جدول ٦٧ محافظة (اليمن والسعودية والخليج ومصر والشام والعراق والمغرب العربي) — فتظهر «حضرموت» بدل الأرقام.

التسمية الاحتياطية المحلية تقديرية، وليست مطابقة لحدود المحافظات. إن لم تتوفر تسمية قريبة، يظهر «موقعك الحالي» دون الاحتفاظ باسم الموقع القديم. اختيار مدينة يدويًا يوقف التحديث التلقائي إلى أن يختار المستخدم «استخدام موقعي الحالي».
