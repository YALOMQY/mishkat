Build “Pocket Quest,” a mobile-friendly web app that turns everyday walks into whimsical, procedurally generated adventures.

- Generate quests from local landmarks, weather, time of day, and walking distance.
- Let players collect virtual creatures by completing photo, trivia, or movement challenges.
- Create a daily shared “world boss” powered by the community’s total steps.
- Award collectible badges and funny AI-written travel journals after each expedition.
- Include a privacy-first mode using approximate location and on-device progress storage.
